# Atlas Beta redesign — implementation plan

Source: `design/current/design_handoff_atlas_beta/` ("Atlas App Beta Redesign.zip",
sha256 `712ce990…`, pulled 2026-10-27). Baseline it is diffed against:
`design/previous/design_handoff_atlas_suite_v2/` (the August suite-v2 port).

The handoff's own README sets the rule this plan follows: **implement the
features, not just the look**. Every control and state visible in a `.dc.html`
is in scope; where the app has no source for a designed feature, the feature is
built (data model, Rust/brain plumbing, persistence, tests), or a typed adapter
with a fixture stands in so the UI is real and the source can be filled later.
No visible control may do nothing.

Progress is tracked on the roadmap site (atlas-roadmap, phase **Beta
redesign**, tasks `b1`–`b8`), one task per handoff phase.

## 2. Phase 2 · Home and widgets (`b2`)

`Atlas Dashboard Beta.dc.html` → `AtlasDashboard.tsx` / `AtlasHome.tsx`; `Atlas Widgets Beta.dc.html` → `AtlasWidgetCatalog.tsx`, `AtlasWidgetSheet.tsx`; `Atlas Widget Screens Beta.dc.html` → new `src/pages/atlas/widgets/*`.

- Stage band (tall): sphere, greeting (date eyebrow, "Good afternoon, <name>.", one line of context, suggested asks), focus card (one primary, one secondary action).
- Three layouts: Stage, Grid, Centred (Grid/Centred get the light pass; to be retired later).
- Status panels (Wi-Fi, Bluetooth, Devices, Battery): floating panel shell 336 px, radius 22, white 92 % + blur, title + switch, current-state card, group label, rows, settings link → `/settings#wifi` etc. Off state = empty state with one action.
- Edit Home: drag reorder, S/M/L, add/remove, capacity meter, layout switch, Cancel restores. Persistence per the handoff's persistence spec (not in the bundle; use the app's dashboard-layout store `useDashboardLayout`).
- Widgets: every type in the catalog, × S/M/L × paper/ink × data/empty; states loading/default/attention/empty/offline for the six core widgets. Now playing: like, output switching, seek, prev/next, shuffle, repeat, volume, up next, live progress (librespot).
- Each widget opens its standalone screen with the hero morph: Weather (WebGL sky `atlas-weather-sky.js`, follows the hour, tap-to-preview, air quality), Calendar (free-slot booking), Tasks (delegate to Atlas), Briefing (listen), Podcast (chapters), Focus (timer that holds notifications). Others go to Mail, Money, Clock, Music, Health, Smart Home.

**Status (2026-10-27, `cbb121c`):** shipped behind the flag — `BetaHome.tsx` takes `/`;
stage band (`home/StageBand.tsx`, reading in `lib/stageFocus.ts`), one face for every
widget (`home/WidgetFace.tsx`) with thirteen live adapters (`home/widgets.tsx`), Edit Home
(`home/EditHome.tsx`, model in `lib/betaHome.ts`), persistence through the shared
`dashboard_layout` table (`lib/betaHomeSync.ts`, `hooks/useBetaHome.ts`), the three
layouts (Grid/Centred as the light pass), status panels (`home/StatusPanels.tsx`), and the
Talk panel's header-sphere mode. Deliberate departures: the status panels carry no Wi-Fi /
Bluetooth switch (no command behind it); the full view reuses `AtlasExpanded` until the
widget screens land. **Still open in b2:** the standalone widget screens
(`Atlas Widget Screens Beta.dc.html`), Now playing's like / output / shuffle / repeat /
volume / up next, the catalog and sheet restyle (`Atlas Widgets Beta.dc.html`), and the
Mac check (dashboard is behind auth, so the browser preview cannot show it).

**Status (2026-10-28) — the rest of b2 shipped:** the widget screens
(`home/views/` — Weather with the WebGL sky in `lib/weatherSky.ts`, Calendar with real
free-slot booking, Tasks with delegate-to-Talk, Briefing with Listen, plus Watchlist and
Music in the Beta frame) replace `AtlasExpanded` in Home's full view; the catalog and sheet
are one page, `BetaWidgetCatalog.tsx`, on `/widgets` and `/widget-sheet` (admin), drawing

Atlas's 16 real widgets in their seven real groups, not the design's mock list; Home's live
widgets do not switch into the attention/offline states on their own yet.

## 3. Phase 3 · Communication and knowledge (`b3`)

- **Mail** (`Atlas Mail Beta` → `AtlasMail.tsx`): lanes Needs you / Atlas handled / Inbox / Snoozed / Sent / Archive; per-account rules; per-message Atlas card with approve + undo; drafts with rewrite options; snooze incl. - **Answer Views** (`AtlasAnswerViews.tsx`): question → shape routing (weather, spending, departures, comparison, person, explainer) from the brain's structured output; sphere thinks centre then moves to the corner.
- **Core / Teach / Architecture**: tailored heroes (ink orbit lab; sphere-as-mic; isometric layer stack) + existing bodies.
- **Voice** (`Atlas Voice Beta` → new `AtlasVoice.tsx`): the sphere-led conversation surface.

**Status (2026-10-27) — Mail shipped behind the flag:** `BetaMail.tsx` takes `/mail`
(App.tsx override); `src/components/atlas/mail/` (MailLanes, MailList, MailReader,

statuses (`needs_you`, `inbox` added to `MailView` and `useAtlasMail`, not to the Workshop
sidebar). Departures, all because of what exists underneath: no "Archive" (the model has

## 6. Phase 6 · System and agent (`b6`)

Agent View (run list, goal + limit, pause, stop-and-undo, plan with inline approvals, live activity log streamed from the brain), System Status (health headline with sphere, uptime/actions/model calls, device battery rings, services with latency sparklines, on-Mac storage, recent events, re-check runs the real probes), Dev tools (Tests, Versions, Design Sync).

**Status (2026-10-28) — Agent View and System Status shipped behind the flag (admin):**
`BetaAgentView.tsx` merges agent runs, the brain's agent sessions and the approval queue;
there is no Pause (nothing can pause a run), "Stop and undo" is "Stop run" on live agent
runs only, progress is unmeasured (nothing writes a planned step total), and a live
session's log is polled every 5 s. `BetaSystemStatus.tsx` lists only the two services the
brain probes, fills its latency bars from this session's own checks, shows row counts per
table instead of megabytes, and its Model calls tile reads a table nothing writes yet.
`BetaDevTools.tsx` (admin) serves `/tests`, `/versions` and `/design-sync`: real test runs
per CI job, the version plan with sync status, and a new brain route that maps each
`.dc.html` to the code that implements it. No coverage figure, no release channels
(promote / roll back) and no tester counts: nothing underneath records them.

## 8. Phase 8 · Polish and cutover (`b8`)

Accessibility (focus order, labels, reduced motion), performance (particle budgets, pausing off-screen spheres), phone-width checks, the final dock once chosen from `Atlas Dock Explorations`, then `beta_ui` default on, flag and old screens removed.

## 9. Decisions this plan takes without asking

- **Sphere engine:** the Beta veil engine is ported as a second engine (`quickSphere.ts`) rather than retrofitted into `atlasSphere.ts`; the old engine stays for the non-Beta screens until phase 8 removes them. One state bus feeds both.
- **Focus ring:** the guidelines forbid focus rings; the app's accessibility rule (`--focus`) stays on keyboard focus only (`:focus-visible`), invisible to pointer users. That satisfies both.
- **Voice accent:** `--acc2` orange is not used by the Beta shell; the sphere's state tint carries the listening colour.
- **Name in the greeting:** the handoff says "Marcus"; the app uses the signed-in account's name.
- **Site and Support console:** out of scope (handoff says so); iOS not designed.
