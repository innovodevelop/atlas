## Confirmed (14)

### The voice-lifecycle cluster — 5 findings, one theme
Every confirmed error/security finding in the webview is a **mount/unmount
lifecycle leak in the voice stack**:

| # | Where | What |
|---|---|---|
| C1 | `useVoiceSession.ts:276` | Unmount never cancels the WS reconnect timer → every Home↔Dashboard navigation spawns a **zombie voice session** 3s later, `hello`-authenticated with the live JWT, that nothing ever closes. |
| C2 | `useRealtimeScribeStable.ts:266` | Unmount never disconnects the ElevenLabs scribe socket → **the mic can keep streaming audio to a third party** after leaving `/atlas-teach`. `useLoginVoice` fixes this exact leak for the same library, with a comment saying why. |
| C3 | `wakeWord.ts:224` | `destroy()` never releases the ONNX `InferenceSession`s → WASM memory leaks per session cycle. |
| C4 | `voice-gateway session.ts:402` | `VoiceSession.destroy()` never releases the Silero VAD engine → each zombie reconnect (C1) leaks server-side too. |
| C5 | `useVoiceSession.ts:11` | The header *claims* this hook replaced `useStreamingTTS`/`useRealtimeScribeStable`; both remain live on reachable routes — two voice stacks that drift independently. |

## The critic's gaps (10) — what the sweep structurally missed

1. **Everything was static.** No agent ran the app. #48 (blank window after
   idle) and #38 (control port never runtime-verified) remain unreproduced, and
   the confirmed leaks' actual memory cost is unmeasured.
2. **The Tauri IPC boundary**: 26 commands reachable from the webview with no
   tier/audit model, next to a control port that has both — diff the two
   surfaces command by command.
3. **The ship path**: hardened runtime + unsigned sidecars + notarization +
   updater upgrade have never been exercised end to end on an artifact.
4. **A vacuous CI gate**: the edge-functions job loops `for d in */`, skips
   `_shared`, and `supabase/functions/` contains *only* `_shared` — the job
   passes while checking nothing.
5. **CSS**: `workshop.css` (121 KB source) loads eagerly for every surface;
   unused fraction unmeasured.
6. **The test suite can't catch the bug class we found**: no test
   mounts-and-unmounts a hook; all five lifecycle leaks were invisible to it.
7. **Schema drift**: 68 tables owned by Rust DDL, queried by a second process
   (brain, via bun:sqlite) with no version stamp and no cross-check.
8. **URL opener surface**: `openExternal`/`openUrl` call sites with
   remote-derived URLs and no scheme allowlist.
9. **Locale**: 18 of 35 `toLocale*` call sites pass no locale — a Danish-set
   Mac renders a mixed dashboard.
10. **Two-writer concurrency** (Atlas + Lighthouse) is documented but has never
    been observed live.

These become work items in the refactor plan (`2026-08-11-refactor-plan.md`),
not a appendix nobody reads.
